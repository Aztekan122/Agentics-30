# Layer Map (High-Level)

Agentic‑30 is divided into six functional blocks:

- Block A — Input & Constraint Layers (1–5)
- Block B — Interpretation Layers (6–10)
- Block C — Reasoning Layers (11–15)
- Block D — Supervisory Layers (16–20)
- Block E — Orchestration Layers (21–25)
- Block F — Output & Stability Layers (26–30)

Each block enforces strict boundaries and predictable behaviour.
